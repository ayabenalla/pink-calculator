# Pink Calculator 🎀

A unique, pink-themed interactive calculator created specifically for women, combining functionality with a fun and engaging user experience.

## ✨ Key Features

- 🌸 **Women-Centric Design:** Beautiful pink interface tailored for an aesthetic and comfortable user experience.
- 🎭 **Interactive Emojis:** Fun emojis pop up whenever you press buttons or perform calculations.
- 🎤 **Voice Assistant (6 Languages):** Built-in microphone support allowing voice inputs in Moroccan Darija, English, French, Spanish, Korean, and Chinese.
- 🎨 **Drawing Canvas:** A dedicated drawing feature for taking notes or creative sketching.
- 🎬 **Video Demo Included:** Full video demonstration available in the repository (`Pink_Calculator_Demo.mp4`).
